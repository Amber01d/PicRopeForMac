# PicRopeFM（PicRopeForMac）

> **把截图挂起来，随手取用。**

[PicRope](https://github.com/Renly1994/PicRope)（Windows 截图暂存/贴图工具）的 Mac 版重实现。
原生 Swift + AppKit，**零第三方依赖**，单包约 100KB。

## 一句话部署

把这句话发给你的 AI 助手——"请阅读 https://github.com/Amber01d/PicRopeForMac 的 README 并帮我安装 PicRopeFM"，剩下的让它搞定。

## 功能总览

### 1. 收集（两条通道）

| 通道 | 默认 | 说明 |
|---|---|---|
| **剪贴板收集**（核心） | 开 | 任何写入剪贴板的截图工具（iShot、Snipaste、微信 Alt+A、`Ctrl+Cmd+Shift+4` 等）截完自动挂上绳子；内容哈希去重、复制自我回收保护 |
| **文件夹监听**（辅助） | 关 | 任意路径自由配置（自动识别 `~/Pictures/屏幕截图` 等本地化目录名，支持中文路径/文件名）；**基线 + 轮询**：启动只建基线不回灌历史图片，运行时每秒轮询，仅新增图片挂上 |

> **注意**：macOS 系统截图在预览浮窗消失前不会落盘，文件夹监听因此无法做到“实时”上绳；追求实时请用剪贴板通道或第三方截图工具。

### 2. 绳子

- 麻绳质感曲线（投影/主体/暗部/高光/捻纹五层绘制），中部下垂，衣夹悬挂
- 挂图从**中心向两侧交替延伸**；方块大小按屏幕宽度和张数**自适应**（基准可在设置中调），放不下回退横向滚动
- 正方形缩略图（中心裁剪，无视原比例）
- **悬停高亮**：强调色边框 + 轻微弹起 + 手型光标
- 鼠标离开 0.35s 自动收起；可设置**常驻屏幕**（不自动收起，手动显隐始终有效）
- **背景全透明**模式：只留绳子和截图本体
- **每屏独立记忆**：绳子位置（上下偏移）按屏幕分别保存，换屏自动套用该屏记录

### 3. 操作速查

| 动作         | 效果                                                |
|------------|---------------------------------------------------|
| 单击图片       | 复制（屏幕居中 HUD 提示）                                   |
| 双击图片       | 钉到桌面                                              |
| 双击被钉图片     | 关闭被钉图片                                            |
| 右键图片       | 复制 / 钉在桌面 / 存储到… / 删除此图片 / 移除除此之外所有图片 / 删除绳子上所有图片 |
| 拖动绳子   | 上下移动绳子                               |

### 4. 桌面贴图

置顶小窗，任意位置按住拖动，滚轮以图片中心缩放，**双击关闭**，右键复制/关闭。

### 5. 更新检查

- 设置中可选**启动时自动检查更新**（是/否，默认开）：有新版本时弹窗提示
- 设置中**检查更新**按钮：手动检查，直达 GitHub Release 下载页

### 6. 菜单栏（点击状态栏图标）

```
显示绳子 / 隐藏绳子 / 清空绳子
─────────────
重置绳子位置
移动到屏幕 ▸ <其他屏幕列表，动态刷新>
─────────────
设置…
─────────────
退出 PicRopeFM
```

### 7. 设置（点「确定」才生效）

剪贴板收集 / 文件夹监听与路径 / 绳子常驻 / 背景全透明 / 启动时自动检查更新（是/否） / 默认截图卡片大小（40–240pt，步进 8） / 开机自启动（SMAppService，勾选即注册） / **初始化设置**（一键恢复全部默认值）。

### 8. 持久化

- 截图自动落盘 `~/Library/Application Support/PicRopeForMac/captures/`，**重启恢复**
- 所在屏幕、每屏位置、常驻、透明、监听路径、更新选项等设置全部持久化
- 绳子上限 50 张（含磁盘文件同步淘汰）；删除操作同步删除磁盘文件

## 安装

> **一句话上手**：把这个链接发给你的 AI 助手——"请阅读 https://github.com/Amber01d/PicRopeForMac 的 README 并帮我安装 PicRopeForMac"，剩下的让它搞定。

```bash
git clone https://github.com/Amber01d/PicRopeForMac.git
cd PicRopeForMac
./build.sh        # 构建 release、ad-hoc 签名、打包 PicRopeForMac.app + zip
open PicRopeForMac.app
```

或开发模式：`swift build && ./.build/debug/PicRopeForMac`

发版：改 `build.sh` 顶部 `VERSION`（如 `PRFM.0.2`）→ `./build.sh` → 提交合并 → `git tag PRFM.0.2 && git push origin PRFM.0.2` → GitHub 发 Release 传 zip，旧版本会自动收到更新提示。
